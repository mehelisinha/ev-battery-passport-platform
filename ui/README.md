# UI — React 18 + TypeScript SPA

Placeholder scaffold. The full app is built in **Phase 5** (roadmap Step 5.2)
so it slots onto working API endpoints rather than being stubbed early.

Scaffold when you reach Phase 5:

```bash
cd ui
npm create vite@latest . -- --template react-ts
npm install react-router-dom @tanstack/react-query tailwindcss recharts leaflet d3
```

Pages (PRD Section 7.1): Passport Viewer, Live Grid Dashboard, Battery Fleet Map
(Leaflet), Second-Life Registry, Lineage Explorer (D3), Compliance Dashboard.
